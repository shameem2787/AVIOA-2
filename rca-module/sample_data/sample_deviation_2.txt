Deviation Title: Assay OOS – Amoxicillin Trihydrate API Batch AMX250918

Date of Occurrence: 12 September 2026
Date Reported: 13 September 2026
Product: Amoxicillin Trihydrate API
Batch / Lot: AMX250918
Area: Quality Control Laboratory – HPLC Room
Process Step: Finished Product Assay Testing
Severity: Major

Description:
During routine release testing, the assay result for Amoxicillin Trihydrate API Batch AMX250918 was found to be 96.2% (specification 97.0% – 102.0%). Retest by a second analyst confirmed the OOS result (96.4%). No instrument malfunction was observed. System suitability parameters were within limits.

Immediate Actions:
1. Batch placed on hold.
2. Retained sample secured.
3. HPLC system locked for investigation.

Impact:
One full batch (approximately 180 kg) under hold. Potential delay in customer shipment.
